# Example data

`transactions.csv` is synthetic demonstration data. It is not a real wallet trace, real transaction history, or evidence of activity by any person or organization.

Run the offline analyzer with:

```bash
halloween-osint ledger analyze examples/transactions.csv
```

Use real exports only when you have authority to handle them. Preserve the original export and document its source, retrieval time, chain, asset units, and extraction method separately.
